需要改变选型时补：需求或学习目标（有故障时才附原始错误） → 已有证据与尝试 → 最小替代 → 迁移代价 → 验证方法 → 实际结果及源码/提交。没有真实比较就写“依据契约选择，未实测替代”，不要虚构“试过若干方案最终证明最好”。

Python 3.15 兼容性按本机实际版本组合核对；当前 [PySide6 元数据](https://pypi.org/project/PySide6/) 包含该 Python 范围，但不能推出 GUI、输入和打包全通过，也不构成立即更换环境的理由。
