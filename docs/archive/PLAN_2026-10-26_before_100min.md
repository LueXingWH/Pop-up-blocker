## 目标与验收

首要目标：尽快由用户独立开发出真正可安装、可运行、具备完整基本 GUI 的 Windows 窗口清理软件。学习只服务于当前开发，**每项学习任务都必须推进实际功能、必要修复、交互或发布验证**。能解释所用技术是辅助目标；不另排系统性语言课程，不以完成面试题库阻塞开发。

暂定产品名“窗口清理工具”，与原“点选关窗器”是同一项目，继续已有环境、实验和学习记录。目标是具有 GUI、能独立运行并覆盖安装/卸载等发布环节的 Windows 软件；终端脚本用于隔离验证组件。以做促学、以学促做，先用当前功能引出必要原理，再以开发和测试验证理解。

第一版使用 Python + Windows API（优先 pywin32）+ PySide6，样式用 QSS，版本管理用 Git / GitHub，可执行构建用 PyInstaller，安装程序用 Inno Setup。开始清理后光标变化；左键选一个普通窗口，发送正常关闭请求后退出模式；右键或 Esc 取消；过滤自身、桌面、任务栏等目标；保留目标自己的未保存处理。任务栏图标映射留到基本交付通过后。不能用结束进程代替正常请求。

功能验收：普通测试窗口、含未保存内容的测试窗口、取消、重复进入/退出、过滤、光标恢复、打包启动都留下手测记录。遇到无响应、权限较高或特殊窗口，记录结果与限制，不能把发出请求当作关闭成功。

理解验收：能够独立讲解调用流程与关键代码，说明所用技术的作用；关键参数和常量要能说出来源、单位、调整影响及验证方法。功能通过与原理讲清分别记录。

发布验收：记录解释器与依赖版本、构建输入及对应源码提交，包含图标/资源与应用版本信息；在无项目 Python / 源码依赖的测试环境验证独立运行，另行验证安装、快捷方式启动、核心回归、退出、卸载及用户数据策略。核对安装文件和快捷方式清理情况。exe 与安装包分别验收；优先选型已明确为 PyInstaller / Inno Setup，工具版本与兼容性待实际核验，本次不安装或构建。

## 每天怎样使用

教学方式：用户已有算法题 Python 基础，不常规重讲 print、赋值、循环或下标，不另排语言或算法课程。围绕当前开发任务讲清接口、数据流、机制、参数依据和边界；Windows API 按需补必要的 C 签名、句柄和指针背景，不要求转学 C/C++。导师先核对官方资料，写成可独立使用的中文教程，链接作事实来源和可选参考。

后续每份学习单开头固定说明“今天实现的软件功能、工作原理、代码未来接到界面的哪个位置”。UI 外壳可由 AI 协助；核心功能与流程接线由用户手写。Day03—05 先用终端独立验证，GUI 日再实接按钮和状态反馈；不能把接入规划记为已完成功能。

学习前先读真实记录，准备或补齐当天学习单，再开始练习。沿用现有 `lessons/DayNN_YYYY-MM-DD_学习流程.md` 路径；每课包含今日目标、前置知识、系统性教程、开发任务与职责边界、集中面试题、验收及记录、文末参考答案。文件应能独立阅读，不要求频繁询问下一步。

约一小时可分为：5 分钟前置、12 分钟必要教程、25 分钟独立开发、10 分钟手测、8 分钟记录与 Git；可从阅读时间选用 2—3 分钟自主复述。安装排错计时，未完成记录续做，已有证据直接复用。每个当日真正使用的重要模块 3～5 题，集中列题、文末统一答案；不采用逐题交互式考核，不以全题解释通过作为继续开发条件。

卡住时提供：自己的尝试、预期与实际差异、完整报错、已试方法。指导顺序为定位问题、解释原理、实现思路、必要的局部示例/伪代码、用户独立修改、审查与复测。审查说明实际位置、触发条件、原因、修改方向和验证方法，不立即重写整个程序。

每次结束将学习单的完成记录交回，再更新本文件。若没有运行结果，只能记“待验证”；若能运行但讲不清，记录具体知识缺口。
